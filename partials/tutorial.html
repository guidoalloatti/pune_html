How to play
  • Local: select at least 2 worms, assign left/right keys, then press “Create a game.”
  • Online: create, join, or autojoin a room, then “Ready Up.” Host can start the match.
  • Controls: each worm has its own left/right keys to steer continuously.
  • Scoring: last worm alive scores a point each round. First to the target wins.
  • Holes: gaps appear in trails; if “Hole Points” is enabled, passing holes can score.
  • Speed: speed can ramp up randomly; use Pause to breathe.
  • Spectate: in online rooms you can switch to spectator anytime.
  • Mobile: use the on-screen left/right buttons; press and hold to steer.
